Privacy policy

Last updated: 11 October 2026.

Moose Backup is operated by its account owner to protect application source code, user records and recovery configuration.

Google Drive access and use

The utility requests Google Drive access to upload designated backup archives, inspect their metadata and folder permissions, download and verify them, and delete only older backups qualified under the owner-approved retention rules. Its workflow is restricted to configured backup folders. Drive API permission itself may cover the wider Drive account.

Storage and sharing

Recovery archives are stored in the owner’s private Google Drive and designated local backup storage. They can contain user records and confidential system configuration. OAuth credentials are stored in restricted local configuration. The utility does not sell Google user data, use it for advertising or use it to train AI models. Google processes Drive storage and transfers under its own terms. Sanitized application code is backed up separately to the owner’s private GitHub repository.

Retention

The new daily backup class retains the two latest verified generations. An older generation is eligible for removal only after newer recovery copies have passed verification. Initial archives, unrelated files and held failure evidence are preserved separately until the owner reviews them.

Owner control

The owner can stop the backup service, revoke its Google Account access, or manage stored backups. Revoking access stops future access but does not automatically remove existing backup files. This utility has no public account registration.

Contact

Contact the operator using the support email shown on the Moose Backup Google consent screen.
